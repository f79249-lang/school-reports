# مولد تقارير المدارس

هذه النسخة لا تعتمد على JavaScript/PDF.js داخل المتصفح. قراءة الجداول تتم في Python باستخدام PyMuPDF، وقد تم اختبار منطق الاستخراج على ثلاثة تقارير فعلية: وادي ولف، خالد بن الوليد، والعزيزية بمهد عُشرة.

## التشغيل على Streamlit Community Cloud
1. أنشئ مستودع GitHub جديدًا.
2. ارفع الملفات: `app.py` و`requirements.txt` و`moe_logo.png`.
3. افتح https://share.streamlit.io وسجّل الدخول بحساب GitHub.
4. اختر المستودع ثم Main file = `app.py` واضغط Deploy.
5. تحصل على رابط موقع، وتستخدمه دون أي برمجة بعد ذلك.
